# ระบบจดบันทึกงานและปฏิทินส่งงานลูกค้า (Client Task & Schedule Calendar)

เว็บแอปพลิเคชันสำหรับจดบันทึกงาน ติดตามกำหนดการส่งงานลูกค้า และแสดงผลในรูปแบบตารางปฏิทินรายเดือน ใช้งานได้ทันทีผ่านเว็บเบราว์เซอร์

---

## 🌟 ฟังก์ชันการทำงานหลัก

- 📅 **มุมมองปฏิทินรายเดือน (Calendar View):** แสดงตารางปฏิทินรายเดือน รองรับทั้งปี พ.ศ. และ ค.ศ.
- ⚡ **แถบจดงานด่วน (Quick Add Bar):** พิมพ์ชื่องาน, ชื่อลูกค้า, และเลือกวันกำหนดส่ง บันทึกได้ทันที
- 📝 **บันทึกงานแบบละเอียด:** ใส่รายละเอียดเนื้องาน (เช่น 1. ร่างแบบ 2. ประเมินราคา 3. ส่งเอกสาร), สถานะงาน, และระดับความสำคัญ
- 🚨 **ติดตามงานค้างส่ง & เกินกำหนด:** แถบสรุปด้านข้างแสดงงานที่ใกล้ถึงกำหนดส่งและงานที่เกินกำหนดส่ง พร้อมปุ่มติ๊กถูก (✓) เมื่อส่งงานเรียบร้อยแล้ว
- 🌓 **รองรับ Dark Theme & Light Theme:** มีปุ่มสลับโหมดมืด/สว่าง ถนอมสายตา และจำค่าล่าสุดอัตโนมัติ
- 🔍 **ค้นหาและกรองข้อมูล:** ค้นหาตามชื่องานหรือชื่อลูกค้า และกรองตามสถานะงานได้แบบเรียลไทม์
- 💾 **ข้อมูลปลอดภัย ไม่สูญหาย:** บันทึกข้อมูลลงบน Browser LocalStorage ของอุปกรณ์คุณโดยตรง พร้อมฟังก์ชันสำรองข้อมูล (Export JSON)

---

## 🚀 วิธีเปิดใช้งาน

### 1. ใช้งานบนคอมพิวเตอร์ของคุณ (Local)
- ดับเบิลคลิกที่ไฟล์ `open_app.bat` หรือเปิดไฟล์ `index.html` ผ่าน Google Chrome หรือ Microsoft Edge

### 2. ใช้งานออนไลน์ผ่าน GitHub Pages (ฟรี)
เมื่อนำขึ้น GitHub แล้ว สามารถเปิดใช้งาน **GitHub Pages** เพื่อให้มีลิงก์เว็บไซต์ใช้งานได้ทุกที่:
1. ไปที่แท็บ **Settings** ของ Repository บน GitHub
2. เลือกเมนู **Pages** ด้านซ้าย
3. ในส่วน **Build and deployment > Branch** ให้เลือกเป็น `main` และโฟลเดอร์ `/(root)` แล้วกด **Save**
4. รอประมาณ 1-2 นาที คุณจะได้ลิงก์ เช่น `https://<username>.github.io/<repository-name>/` สามารถเปิดใช้งานผ่านมือถือ แท็บเล็ต หรือคอมพิวเตอร์เครื่องไหนก็ได้ทันที!

## 📁 โครงสร้างไฟล์

```text
├── index.html        # หน้าเว็บหลักและโครงสร้าง UI
├── style.css         # สไตล์ตารางปฏิทิน การ์ดงาน และ Dark Mode
├── app.js            # ระบบคำนวณปฏิทิน การจัดการข้อมูล และ LocalStorage
├── open_app.bat      # ช็อตคัตเปิดโปรแกรมสำหรับ Windows
└── README.md         # คำอธิบายโปรเจกต์และคู่มือการใช้งาน
```
